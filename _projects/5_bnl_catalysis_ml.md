## Project Overview

The **BNL Catalysis Machine Learning Project** applies predictive machine learning models to experimental catalysis datasets, featuring an interactive GUI for researchers.

### Key Features
- **Predictive ML Models**: Feature selection and regression modeling evaluating experimental catalyst performance.
- **Interactive GUI**: Python interface enabling real-time dataset loading, visualization, and model execution.
- **Experimental Reporting**: Comprehensive statistical reporting pipeline for research insights.
