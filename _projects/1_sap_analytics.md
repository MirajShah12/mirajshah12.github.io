## Project Overview

The **SAP (Softball Analytics & Sabermetrics Performance)** project is a statistical analysis framework developed in R to evaluate player performance, game situations, and run expectancy metrics in softball.

### Key Features
- **Statistical Pipeline**: Custom R scripts (`SAP.R`, `SAP#2.R`) for processing situational play-by-play data.
- **Run Expectancy & Value**: Situational matrices calculating expected run production across base-out states.
- **Player Evaluation**: Advanced metrics isolating hitter and pitcher contributions beyond traditional box score statistics.
