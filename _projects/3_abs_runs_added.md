## Project Overview

The **ABS (Automated Ball-Strike) Runs Added Model** quantifies the run value saved or conceded by computerized strike-zone calls versus traditional human umpire calls.

### Key Features
- **Run Value Matrix**: Translates ball/strike call differentials into run expectancy shifts.
- **Umpire Accuracy Impact**: Evaluates how missed call rates impact pitcher and batter run values.
- **Challenge System Simulation**: Models optimal challenge strategy for teams under ABS challenge rules.
