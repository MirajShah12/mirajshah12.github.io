## Project Overview

The **Lineup Generator Project** is a Python-based optimization tool designed to construct optimal team batting lineups to maximize run output across simulated games.

### Key Features
- **Combinatorial Optimization**: Evaluates 362,880 possible 9-hitter batting order permutations.
- **Matchup Splits Integration**: Factors in platoon advantages (L/R) and opposing pitcher characteristics.
- **Game Simulation Engine**: Simulates thousands of game iterations to validate expected run production.
